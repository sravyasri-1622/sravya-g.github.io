# HTML, CSS & JavaScript Practicals

This repository contains my HTML, CSS, and JavaScript practical programs created as part of my web development learning.

## About

The project includes different practical programs covering basic web pages, forms, tables, lists, images, CSS styling, responsive designs, and JavaScript programs.

All the programs are organized into separate folders for easy access and better understanding.

## Repository Structure

- `html/` – HTML practical programs
- `css/` – CSS practical programs
- `javascript/` – JavaScript practical programs
- `assets/` – Images and other supporting files
- `nodejs/` – Node.js related practical files
- `index.html` – Main page connecting the different practical sections

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- Git & GitHub
